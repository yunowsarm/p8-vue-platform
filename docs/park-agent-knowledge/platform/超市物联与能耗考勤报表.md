# 智慧园区运营统计和报表办事流程

## 超市销售明细核查
进入「超市物联」，选择业务发生日期范围，点击「查询」，需要时再使用页面内的设备及明细筛选。数据视图可看趋势、汇总和销售明细，点击「详情」核对单条记录。选用按天或按单号的导出入口时，以页面当前查询范围和筛选条件为准。交易日期统计依据交易发生时间，延迟上传的接收时间不作为趋势日期。适用岗位为授权运营人员。

## 超市销售分析报告
在「超市物联」切换「数据分析」，查看交易单数、金额、业务类型、趋势及商品排行，按页面提供的选项导出 HTML 或打印保存 PDF。统计使用整个筛选范围，列表翻页只改变当前展示行。商品分类、支付方式、库存及毛利有待对应数据口径确认，查询时以可见字段为准。

## 用电汇总查询与分析
打开用电汇总，选择起止月份并点「查询」。按页面提供的配电房或电表维度查看数据视图，或切换「数据分析」查看汇总、排名及统计明细。分析页的报告导出以已查询数据为范围。用电预测在提供该视图时作为分析参考，结算以正式计量及账单为准。

## 月度考勤报表核查
在月度考勤报表选择日期范围，点击「查询」，再通过表内搜索和考勤状态筛选记录。核对出勤天数、工时、异常及审批汇总。当前页面按固定查询人员集合调用接口，适合核对该范围，使用前请确认覆盖对象。补卡、请假、考勤申诉以所在单位的审批入口为准。
