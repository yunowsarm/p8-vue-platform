# P8 合同、收付款合同导入及预算办理流程

## 合同维护
有权限的合同经办人员进入合同管理，打开当前业务的合同编辑页面。核对合同文本和「合同属性」，填写合同编号及该合同适用的乙方、租赁位置、面积、租赁起止日期、保证金和租金等字段，点「保存合同」。审批、签署与收费以正式合同和业务流程为准。修改或续租前请先确认相关合同与园区负责人要求。

## 收款合同与付款合同导入
从对应的收款或付款合同业务打开合同导入，选取合同附件，按表单提示提交。导入类型随业务入口选择，提交前核对收款或付款类别及目标业务。导入完成后回到合同列表核对记录。

## 预算申报
在有权限的「预算申报」上下文中打开填报页。需要基于模板编制时点「载入模板」，选择模板并核对科目。按业务要求填写预算数据并保存。预算金额、科目和审批由项目配置及财务制度决定，页面保存后以业务状态确认是否仍需审批。

## 任务预算
在项目预算管理进入任务预算页面，核对任务及对应的预算科目或金额，按当前预算规则填报，核对预算合计与实际执行合计。页面可编辑时点「保存」，执行数据以系统报表为准。

## 项目预算变更
进入预算变更，先确认当前预算状态。页面允许在「执行中」或「变更驳回」发起变更。打开「预算变更」表单，核对预算、填写变更原因及涉及的数据后保存，在同一预算记录下查看变更信息。后续审批以项目的预算流程为准。
