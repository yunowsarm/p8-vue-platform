# 智慧园区 P8 办事导航

## 企业用户办事入口
企业用户使用有权限的企业账号登录 P8。服务大厅承载业务申请和反馈，包括租赁申请、服务需求、建议投诉、数据上报、媒体宣传、资质认定和资源对接。物业故障走物业报修。公共服务可查公告、园区资讯和下载资料，也可在线咨询。配套服务包含会议室预定、设施设备租赁及企业资源信息。办理时先确认是哪一项业务，按对应表单填报，并回到该业务列表查看状态。

## 个人用户与企业政策服务入口
个人用户在生活服务、网上缴费、园区交流等菜单查看对应事项。生活服务的票务、租车、保险等页面各有独立办理或查询范围。政策、政务、企业关怀从对应菜单查看，按具体页面公开的指南或办理入口操作。页面只有资讯或查询时，可在已有线上咨询入口核实下一步。

## 办理进度和菜单显示
园区各业务的入口和按钮取决于登录账号权限、项目或园区菜单配置及记录状态。提交后在原业务列表查记录详情，有审核的事项以页面显示的状态和意见为准。涉及园区收费、合同、审批时限、线下部门及材料清单，按该事项正式指引或负责人确认。未提交表单的助手对话仅属于沟通记录。

## 运营及内部审批入口
园区运营管理账号从相应业务管理菜单查看和处理业务记录。内部工作流从有权限的待办、审批和项目页面处理。无法定位菜单时，先核对当前账号与园区，再核对具体事项是否在账号菜单内。内部审批、设备处理及统计只适用于相应业务岗位。
