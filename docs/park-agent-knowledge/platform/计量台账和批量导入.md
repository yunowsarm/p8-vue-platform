# 智慧园区水电能源与台账导入流程

## 电表、水表与太阳能表台账
有计量台账权限的人员，从电表、水表或太阳能表业务打开各自的导入入口。先下载相应的 Excel 导入模板，按表头整理计量表基础信息，核对设备及所属位置后选择文件导入。处理完成后检查导入提示和台账列表。三个入口分别使用各自模板。发现格式错误时按错误信息检查表格，修正后重新导入。

## 读数与统计核对
用电、用水及太阳能的表计记录与汇总从相应能源菜单进入。先选对表计和时间范围，再区分读数、用量汇总和账单。按有权限的抄表或汇总页面核实读数；物联异常、缺失读数、结算口径及账单异议交由对应能源或物业岗位核实。

## 物业柱网与资格要求管理导入
有后台业务权限的人员，如果在物业柱网或资格要求管理中看到「导入」，应下载对应业务的模板，按该模板填写后选择文件，查看提示并回到原业务核对记录。资格要求管理的批量导入和企业用户发起的资质认定申请分别使用对应入口。
