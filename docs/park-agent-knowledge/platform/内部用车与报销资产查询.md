# P8 内部用车、报销与资产办事流程

## 用车申请批量派车
有权限的调度人员在用车申请业务中打开「批量派车」，核对待调度申请的起止时间、用车人及用车方式。所有勾选申请的用车方式须一致。按表单选择司机、车牌号和用车人，再提交批量派车。申请最初发起和审批规则由所在单位的用车业务配置决定。

## 出车回车合并登记
有权限的用车登记人员在「合并登记」中核对批次申请、司机、车牌号及用车人，检查出车公里数并录入回车公里数。回车公里数须为有效数字且不能小于出车公里数。核对合计里程后点「提交合并登记」，以处理结果提示和申请记录为准。

## 报销明细查询与导出
进入「报销明细」，按项目、费用分类、部门、提交日期筛选。点「查询」查看结果，需要离线复核时点「导出」。该页面用于明细核对和导出。实际填报、审批或报销付款在相应业务入口办理。

## 资产盘存导出
从资产业务打开盘存导出弹窗。选择开始和结束月份，校对月份顺序，点击「导出」取得所选时间范围的盘存文件。若找不到入口，请核对资产菜单权限。该功能使用系统已有的盘存数据。
