# P8 项目策划、计划变更和任务执行流程

## 项目立项与项目资料
有项目权限的人员进入「项目立项」或对应项目业务菜单，定位项目后查看项目资料和页面可用的关联业务。在立项页切换页签可查看对应配置的表单或列表。项目立项的字段、必填校验与提交按钮由项目数据视图及业务配置决定，填报和提交时按当前页面提示操作。

## 需求采集、预审和需求响应
打开需求采集的新增入口，在来源列表选择相应类型并点「确定」，填写所加载的业务表单并按页面操作保存。查看需求详情时，标准版展示市场需求信息、预审意见、需求描述和分析意见，简易版展示预审意见和需求响应确认。以当前业务配置为准。

## 项目策划发布和变更审批
项目策划的经办人员选择对应策划记录，使用该业务的发布或变更入口。弹出提交审批表单时，核对业务记录，按页面提示预选审批人并提交。收到提交成功提示后，回到策划记录或对应审批入口查看进展。发布与变更使用各自的审批入口及节点。

## 计划变更和影响分析
进入计划变更列表，点击「发起变更」打开编辑区，按表单维护变更计划。提交时核对变更类型、原因分类、变更原因和影响分析等信息，按流程配置处理审批人。处理前可打开已选变更的影响分析；可按变更状态、创建日期、变更人员和原因分类查找记录。修改和删除取决于页面提供的操作。

## 我的任务与进度填报
在「我的任务」定位有权处理的任务，打开详情核对任务内容、当前进度和所需业务表单。进入进度区域，按实际情况填进度及进度说明，按页面提示填写完成时间或必填业务表单，然后点「提交进度」或当前节点的「提交」。进度填写适用于页面允许直接办理的末级任务。提交后回到任务列表核对状态。

## 任务派发和问题跟进
在任务派发的选人窗口输入人员姓名并搜索，核对姓名和部门，选中一位人员后点「确定」。项目问题处理页面同时显示原问题与处理表单，按当前业务权限填写处理信息并保存。由流程或消息进入的详情有只读场景。

## 项目统计、监控及依赖设置
计划甘特图、监控甘特图、计划预警、任务统计、计划完成率用于从计划进度和资源维度核对项目情况。请先选择项目和计划版本，再查看对应指标或任务详情。任务依赖、版本、输入输出和资源的实际调整，应从当前有编辑权限的计划页面进入，具体按钮和审批路径以项目配置为准。
