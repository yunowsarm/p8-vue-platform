# 园区会议室预约、预定和进度查询

## 企业怎么预定会议室

登录 P8，进入「配套服务 → 会议室预定」，点击「新增预定」。选择 1 号、2 号、3 号或多功能会议室，填写开始时间、结束时间、联系人、联系电话和预定用途，点「提交预定」。可选会议室以表单为准。

## 如何确认会议室是否预定成功

回到「会议室预定」列表，打开申请查看状态。提交后先进入「待确认」，此时可以编辑。运营人员查看尚未过期的待确认申请后，状态转为「确认中」，可以确认预定或驳回。确认后状态为「已预定」。已驳回的申请可以修改并「重新提交」。预约结束时间已过的记录显示「已过期」，此时无法确认，需重新选择使用时段。
