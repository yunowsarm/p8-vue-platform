# 智慧园区 P8 办事流程知识库

从[园区办事导航](platform/园区办事导航.md)可查各端业务入口。每份流程文档整理了相应页面能确认的办理步骤、资料字段、状态、查询方式或受理动作，并附本地核对依据。

| 业务范围 | 文档目录 | 涵盖事项 |
| --- | --- | --- |
| 企业端 | [enterprise](enterprise/) | 服务大厅、续租退租扩租、公共服务、会议室和设备租赁、物业报修 |
| 个人端与政企服务 | [resident-gov](resident-gov/) | 生活服务、租车投保、消费订单、园区交流、政策服务、行政审批和企业关怀 |
| 运营端 | [operations](operations/) | 业务受理、公告与社区管理、生活服务维护、招商和房源、报修与消防维保、道闸和智慧物联 |
| 办公、项目与统计 | [platform](platform/) | 审批、会议纪要、用车和报销、项目计划、合同预算、表计台账和运营报表 |

## 使用口径

- 依据当前 P8 项目中的页面、表单配置、接口调用及配套说明整理。实际可见菜单、数据范围和可办理操作以登录账号及园区的线上配置为准。
- 对资讯、只读查询、订单台账和模拟界面，文档注明可验证的能力。正式收费、办理时限、线下材料和合同承诺以对应业务正式指引为准。
- 向量入库使用省略源码出处后的通用流程正文，索引文件名与本地流程文件对应。本目录索引用于人工查找。
